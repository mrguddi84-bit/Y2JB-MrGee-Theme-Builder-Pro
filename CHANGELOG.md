# Changelog

## 3.0 — source baseline (2026-10-30)

* Integrated parallel native BC7 encoding without external texconv executable.
* Compared encoder quality and speed against texconv using real icon and 4K background artwork.
* Added Classic / Minimal / Neon layouts and five-language UI.
* Added/refined PS5 FTP discovery, ftpsrv/zftpd/elfldr controls and permission diagnostics.
* Added backup-and-verify upload workflow with SHA-256 verification, overwrite prompts and icon protection.
* Fixed dropped upload jobs when an FTP check was in progress.
* Extended PS5 app-name database editing and backup handling.



## 2.0 — previous public release

* Streamlined Windows installation and user interface.
* Multilingual interface: DE, EN, ES, FR, PT.
* Dashboard, ThemeCreator, FTP upload and packaging improvements.
