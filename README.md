# Y2JB MrGee Theme Builder Pro

**Deutsch** | [English](#english)

## Deutsch

**Y2JB MrGee Theme Builder Pro** ist eine unabhängige Windows-Anwendung zur Vorbereitung von Theme-Grafiken und zum optionalen Übertragen erzeugter Dateien an einen kompatiblen PS5-FTP-Dienst.

### Funktionen
- Theme Studio zur Bearbeitung und Vorbereitung von Grafiken
- Bildkonvertierung für die benötigten Theme-Dateien
- Erstellung eines PS5-Dateipakets
- Optionaler FTP-Upload mit Bestätigung vor dem Überschreiben vorhandener Dateien
- Windows-EXE zum direkten Starten

### Installation und Verwendung
1. Lade das Windows-Paket aus den **Releases** herunter und entpacke es in einen beschreibbaren Ordner.
2. Starte `Y2JB_Theme_Creator_MrGee.exe`.
3. Wähle deine Grafiken im Theme Studio aus und erstelle das PS5-Paket.
4. Falls du den Upload nutzt, konfiguriere IP-Adresse und FTP-Port (standardmäßig 2121).
5. Prüfe Zielpfad und Überschreibabfrage und sichere Originaldateien vorher.

**Sicherheit:** FTP ist unverschlüsselt. Nutze den Upload nur in einem vertrauenswürdigen lokalen Netzwerk. Veröffentliche den FTP-Dienst nicht im Internet. Änderungen an Zieldateien erfolgen auf eigene Verantwortung und nur auf Systemen, zu deren Änderung du berechtigt bist.

## English

**Y2JB MrGee Theme Builder Pro** is an independent Windows application for preparing theme graphics and optionally uploading generated files to a compatible PS5 FTP service.

### Features
- Theme Studio for preparing and editing graphics
- Image conversion for theme assets
- PS5 package creation
- Optional FTP upload with confirmation before overwriting existing files
- Ready-to-run Windows executable

### Installation and usage
1. Download the Windows package from **Releases** and extract it into a writable folder.
2. Launch `Y2JB_Theme_Creator_MrGee.exe`.
3. Select your images in Theme Studio and create the PS5 package.
4. For uploads, configure the target IP address and FTP port (default: 2121).
5. Verify the destination and any overwrite confirmation, and back up original files first.

**Security:** FTP is unencrypted. Use uploads only on a trusted local network; do not expose the FTP service to the internet. Only modify systems and files you are authorized to manage.
